Service commun aux quatre branches, événement canonique unique, compte commun et exactement un profil produit propriétaire du même compte. Accès autorisé par le produit et les permissions de la ressource. L'interface utilisateur reste propre à chaque branche. L'ancien module Network est conservé dans ../../archive/legacy-network/middleware/src/modules/agenda.ts comme référence historique, non exécutable isolément. Aucune API Agenda n'est connectée en production ; modèle et interfaces à valider en Phase B.
